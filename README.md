# arbol-genealogico

Web pública del árbol genealógico Leblic: https://lucasague.github.io/arbol-genealogico/

Este repo solo lleva lo publicable (`index.html` y `datos.json`), generado por
`herramientas/generar.py` desde las fichas privadas del miniproyecto
`personal/proyectos/miniproyectos/arbol-genealogico`. No se edita a mano: se
regenera solo al cambiar una ficha. Las personas que pueden estar vivas no se publican.
